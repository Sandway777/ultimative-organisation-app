# Hier kommt die Design-Spec rein

Die Textfassung, nach der die App umgebaut wird:

- `tokens.md` - Token-Verzeichnis, eine Spalte je Fassung
- `komponenten.md` - Komponentenregeln in Worten
- `umschalter.md` - falls extra beschrieben: wie die Fassungen umgeschaltet werden

Diese Dateien liest Claude Code und baut danach `index.html` um.
